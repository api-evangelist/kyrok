# Kyrok

> Kyrok GmbH is a Berlin-based software company building an AI operating system for
> mid-sized pharmaceutical and chemical manufacturers in Europe. The platform layers
> over an existing ERP and connects customer service, production planning, material
> planning and procurement into intelligent operations under an "AI assists, people
> decide" model. Kyrok connects to ERP systems via API but publishes no public
> developer API, API reference, or SDKs as of 2026-07-19.

## API status

Kyrok has no public API surface at this time. There is no developer portal, API
reference, OpenAPI description, sandbox, SDK, CLI, MCP server, webhook catalog, or
/.well-known/ discovery document. ERP connectivity is delivered as part of the
commercial engagement rather than as a self-serve public API.
